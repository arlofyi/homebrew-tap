# arlofyi/homebrew-tap

Homebrew formulae for [Conduit Code](https://conduitcode.dev).

```bash
brew install arlofyi/tap/conduit
conduit login
```

`Formula/conduit.rb` installs the `@conduitcode/cli` npm package on Homebrew's
Node. It is generated by `scripts/homebrew-formula.mjs` in
[arlofyi/conduit-code](https://github.com/arlofyi/conduit-code) after each npm
release.
